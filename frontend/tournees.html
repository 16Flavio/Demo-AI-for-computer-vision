Comment ça marche ?How does it work?

Les distances à vol d'oiseau entre tous les points sont calculées (formule de Haversine), puis le solveur Google OR-Tools cherche l'ensemble de tournées le plus court qui respecte la capacité de chaque véhicule (problème de tournées de véhicules, ou VRP). Le trajet naïf visite les points dans l'ordre où vous les avez placés. Le calcul est limité à une seconde.

The straight-line distances between all points are computed (haversine formula), then the Google OR-Tools solver looks for the shortest set of routes that respects each vehicle's capacity (the vehicle routing problem, or VRP). The naive route visits the points in the order you placed them. The computation is limited to one second.
